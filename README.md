# SCG — ONE SYSTEM
Initial 60-second Remotion typography prototype, 1920×1080, 60fps.

## Render on GitHub
Upload these files preserving folders. Open Actions → Render SCG Film → Run workflow. Download the artifact ZIP after completion.

## Local
`npm install && npm run render`

This is a preliminary typography prototype, not a finished Apple-style brand film. Original logo and licensed music are not included.
